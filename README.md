# 💰 Personal Expense Tracker

A simple and responsive web application designed to manage personal income and expenses. It helps users track their spending, calculate their remaining balance, and visualize expenses through charts.

## 🚀 Features

- Add income and expense transactions.
- Select categories such as Food, Travel, Shopping, Education and Bills.
- Calculate total income.
- Calculate total expenses.
- Display remaining balance.
- View transaction history.
- Delete individual transactions.
- Clear all transactions.
- Visualize expenses using a doughnut chart.
- Automatically save transactions using Local Storage.
- Responsive design for desktop and mobile devices.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Application functionality and calculations.
- **Chart.js** – Expense visualization.
- **Local Storage** – Saving transaction data in the browser.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Extract the project folder.
3. Open the folder in Visual Studio Code.
4. Open `index.html` in your browser.
5. Start adding income and expense details.

**Note:** An internet connection is required to load the Chart.js library.

## 📌 GitHub Pages Deployment

1. Open your GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch.
6. Select the `/ (root)` folder.
7. Click **Save**.

Your website will be published using GitHub Pages.

## 💾 Data Storage

This application uses browser Local Storage to save transaction details. Data stays in the browser on the device where it was entered. It is not stored in an online database.
